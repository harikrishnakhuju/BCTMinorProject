\chapter*{Abstract}
\normalsize
Facial recognition technology has witnessed remarkable advancements in recent years, emerging as a pivotal tool across diverse industries for identity verification and access control.  The proposed system aims to enhance security measures, streamline access control, and provide valuable insights into user behaviors across various applications. This proposal introduces a comprehensive system that integrates multi-target facial recognition with real-time tracking capabilities. Leveraging cutting-edge computer vision algorithms, deep learning-based face
recognition algorithms and real-time tracking software, this system offers a versatile solution applicable in settings ranging from secure facilities to retail environments.
       The system architecture incorporates facial recognition algorithms, a database of facial templates, high-quality camera systems, and real-time tracking software. By providing instant identification and continuous tracking of recognized individuals, the system offers a robust security mechanism and the ability to monitor user activities in real-time.\\
\\
\textbf{Keywords:}\text{ Face detection, Face recognition, Tracking multiple face}
